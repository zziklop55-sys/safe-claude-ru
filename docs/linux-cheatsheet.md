# Шпаргалка: Linux для тех, кто привык к Windows

```text
================================================================
  ШПАРГАЛКА: LINUX ДЛЯ ТЕХ, КТО ПРИВЫК К WINDOWS
  Ubuntu 24.04
================================================================

Терминал: Win+Enter (обычный), Win+Backspace (плавающий).
Копировать / вставить в терминале: Ctrl+Shift+C / Ctrl+Shift+V
(обычный Ctrl+C в терминале ПРЕРЫВАЕТ команду — это не копирование).
Tab — дописывает имя файла/команды. Стрелка вверх — прошлая команда.
Ctrl+R — поиск по прошлым командам. Ctrl+L — очистить экран.


----------------------------------------------------------------
1. ЧЕМ LINUX ОТЛИЧАЕТСЯ ОТ WINDOWS
----------------------------------------------------------------

Windows                         Linux
-------                         -----
Диски C:, D:, E:                Нет букв. Всё растёт из одного корня /
                                Флешки и диски появляются в /media/<имя>/...
C:\Users\<имя>                  /home/<имя>   (коротко: ~ )
C:\Program Files                /usr/bin, /opt  (сам туда не лезешь)
Обратный слэш \                 Прямой слэш /
Регистр не важен: File=file     ВАЖЕН: File.txt и file.txt — РАЗНЫЕ файлы
Расширение решает всё (.exe)    Программы без расширения, решает «право на запуск»
Скачал .exe с сайта             Ставишь из репозитория одной командой (apt)
Администратор                   root. Разово: команда с sudo перед ней
Скрытые файлы — галочка         Скрытые файлы — имя начинается с точки: .config
Диспетчер задач                 btop (в терминале) или htop
Панель управления / реестр      Текстовые файлы настроек в ~/.config


----------------------------------------------------------------
2. ГДЕ ЧТО ЛЕЖИТ
----------------------------------------------------------------

~                 твоя домашняя папка (/home/<имя>) — здесь всё твоё
~/Рабочий стол    рабочий стол
~/Загрузки        загрузки браузера
~/Документы       документы
~/Изображения     картинки и скриншоты
~/.config         НАСТРОЙКИ программ (аналог AppData\Roaming)
~/.config/sway/config        настройки рабочего стола Sway
~/.config/waybar/            верхняя панель
~/.config/kitty/kitty.conf   терминал
/media/<имя>/       флешки
/etc              системные настройки (менять только с sudo)
/tmp              временные файлы, чистится при перезагрузке

ВАЖНО: в именах «Рабочий стол» есть пробел. В терминале пиши в кавычках
"~/Рабочий стол" или через \ : ~/Рабочий\ стол  (или жми Tab — допишет сам).


----------------------------------------------------------------
3. ХОДИТЬ ПО ПАПКАМ
----------------------------------------------------------------

pwd                     где я сейчас
ls                      что в папке
ls -la                  подробно и со скрытыми файлами
cd Документы            зайти в папку
cd ..                   на уровень вверх
cd ~   или просто  cd   домой
cd -                    вернуться в предыдущую папку
xdg-open .              открыть текущую папку в проводнике
xdg-open файл.pdf       открыть файл программой по умолчанию


----------------------------------------------------------------
4. ФАЙЛЫ И ПАПКИ
----------------------------------------------------------------

mkdir проекты                    создать папку
mkdir -p a/b/c                   создать вложенные сразу
touch заметка.txt                создать пустой файл
cp файл.txt копия.txt            копировать
cp -r папка папка2               копировать папку целиком
mv старое.txt новое.txt          переименовать
mv файл.txt ~/Документы/         переместить
rm файл.txt                      удалить (БЕЗ корзины, навсегда!)
rm -r папка                      удалить папку целиком (осторожно!)
gio trash файл.txt               удалить В КОРЗИНУ (безопасно)

Никогда не запускай:  sudo rm -rf /   — это снос всей системы.


----------------------------------------------------------------
5. СМОТРЕТЬ И ИСКАТЬ
----------------------------------------------------------------

cat файл.txt             вывести файл целиком
less файл.txt            листать (q — выход, / — поиск)
head -20 файл.txt        первые 20 строк
tail -f лог.txt          смотреть лог в реальном времени (Ctrl+C — стоп)
nano файл.txt            простой редактор прямо в терминале
                         (Ctrl+O — сохранить, Ctrl+X — выйти)
code .                   открыть текущую папку в VS Code

fd отчёт                 найти файл по имени (быстро)
rg "слово"               найти текст во всех файлах папки (быстро)
du -sh *                 сколько места занимает каждая папка
df -h                    сколько места на дисках


----------------------------------------------------------------
6. ПРОГРАММЫ: УСТАНОВКА И УДАЛЕНИЕ
----------------------------------------------------------------

sudo apt update                    обновить список программ
sudo apt upgrade                   обновить всё установленное
apt search vlc                     найти программу
sudo apt install vlc               установить
sudo apt remove vlc                удалить
sudo apt install ./файл.deb        установить скачанный .deb
                                   (.deb — это как установщик .exe)
snap list                          программы из Snap (Firefox, Telegram)


----------------------------------------------------------------
7. ПРОЦЕССЫ (ДИСПЕТЧЕР ЗАДАЧ)
----------------------------------------------------------------

btop                     красивый диспетчер задач (q — выход)
pkill firefox            закрыть программу по имени
killall -9 telegram      убить намертво, если зависла
free -h                  сколько памяти занято


----------------------------------------------------------------
8. СИСТЕМА
----------------------------------------------------------------

sudo reboot              перезагрузка
poweroff                 выключение
systemctl status zapret2           состояние службы
sudo systemctl restart zapret2     перезапустить службу
journalctl -b -p err               ошибки с момента загрузки
fastfetch                          инфо о системе
ip a                               мои IP-адреса
nmcli dev wifi                     Wi-Fi сети вокруг


----------------------------------------------------------------
9. ПРАВА ДОСТУПА (то, чего нет в Windows)
----------------------------------------------------------------

У каждого файла есть права: читать (r), писать (w), запускать (x).
ls -l покажет:  -rwxr-xr-x  → владелец может всё, остальные читать и запускать.

chmod +x скрипт.sh       разрешить запуск файла
./скрипт.sh              запустить файл из текущей папки
sudo команда             выполнить от имени администратора (спросит пароль)

Если пишет «Permission denied» / «Отказано в доступе» —
либо файлу нужен chmod +x, либо команде нужен sudo.


----------------------------------------------------------------
10. ПОЛЕЗНЫЕ ПРИЁМЫ
----------------------------------------------------------------

команда > файл.txt         записать вывод в файл (перезапишет)
команда >> файл.txt        дописать в конец файла
команда1 | команда2        передать вывод одной команды в другую
   пример: ls | grep pdf    — показать только pdf
команда1 && команда2       выполнить вторую, только если первая успешна
команда &                  запустить в фоне
man ls                     справка по команде (q — выход)
ls --help                  короткая справка
history                    все прошлые команды


----------------------------------------------------------------
11. SWAY: ГОРЯЧИЕ КЛАВИШИ (Win = Super)
----------------------------------------------------------------

Win+Enter            терминал
Win+Backspace        плавающий терминал с fastfetch
Win+D                меню программ (начни печатать название)
Win+Q                закрыть окно
Win+1 ... Win+9      рабочие столы
Win+Shift+1 ... 9    перенести окно на рабочий стол
Win+Tab              прыгнуть на прошлый рабочий стол
Alt+Tab              следующее окно
Win+стрелки          фокус на соседнее окно
Win+Shift+стрелки    передвинуть окно
Win+F                на весь экран
Win+Space            сделать окно плавающим / вернуть в сетку
Win+мышь (левая)     таскать плавающее окно
Win+R                режим изменения размера (стрелки, Esc — выход)
Win+W                окна вкладками
Win+E                проводник
Win+B                Firefox
Win+L                заблокировать экран
Print                скриншот экрана в ~/Изображения
Win+Shift+S          скриншот области (и в буфер обмена)
Alt+Shift            переключить раскладку EN/RU
Win+Shift+C          перечитать настройки Sway
Win+Shift+E          выйти из Sway
```
